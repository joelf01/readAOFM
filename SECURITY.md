# Security

Please do not publish details of a suspected security vulnerability,
exposed credential, or private-data issue in a public GitHub issue. Use
the [private security-advisory
form](https://github.com/joelf01/readAOFM/security/advisories/new) with
a concise description, affected version or commit, reproduction steps,
and the minimum material needed to investigate. Do not send live
passwords or tokens.

For ordinary parser failures, changed AOFM workbooks, or documentation
requests, use the public [issue
tracker](https://github.com/joelf01/readAOFM/issues). This repository
does not promise a response time or a coordinated-disclosure process.
The package does not request AOFM credentials; network failures and
upstream workbook changes should be reported as package or source issues
as appropriate.
