# Support

Start with the [package overview](https://joelf01.github.io/readAOFM/),
especially the troubleshooting table and the description of network and
file-output behaviour. Search existing
[GitHub issues](https://github.com/joelf01/readAOFM/issues) before opening a
new one.

Use a new issue for reproducible package bugs, documentation problems, or a
changed AOFM workbook. Include the package version or commit, R version,
operating system, table selector, access date, error message, and a minimal
reproducible example. Do not include passwords, tokens, private data, or
unnecessary downloaded workbooks.

The AOFM Data Hub is an external service. Availability, URLs, workbook
layouts, and source values are controlled by AOFM rather than by this package;
report persistent source-side problems to AOFM as well. For potentially
sensitive security issues, follow [SECURITY.md](SECURITY.md) instead of using
a public issue.
